# CanaryWatch — 60-second pitch

**0–10 seconds — The problem**
Traditional detection often depends on collecting and correlating large volumes of telemetry. CanaryWatch adds a complementary signal: carefully placed deception artifacts that should not be touched during normal workflows.

**10–25 seconds — Set the trap**
Create a synthetic API credential honeytoken. Show its active state and the local-demo placement adapter.

**25–40 seconds — Trigger the alert**
Click “Simulate unauthorized access.” Point to the backend-generated incident, event timeline, severity rationale, and measured processing time.

**40–50 seconds — Rotate**
Rotate the triggered decoy. Show the original marked revoked and the linked replacement token.

**50–60 seconds — Close**
“CanaryWatch is not a replacement for every security control. It adds a low-noise signal: trap, detect, investigate, and rotate—without requiring a heavyweight log pipeline for this signal.”

Be explicit that this demo uses synthetic events and local adapters. Only present benchmark numbers that you measured during your own run.
